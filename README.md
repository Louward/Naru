# Naru — 니케 블라블라

《승리의 여신: 니케》의 메신저 '블라블라'처럼, 니케들과 1:1 또는 단체방에서 채팅하는 개인용 팬 프로젝트입니다.

- 니케마다 성격과 말투를 설정 파일로 정의하고, AI가 그 캐릭터로 답장합니다.
- 단체방에서는 이름이 불린 니케가 먼저 답하고, 다른 니케가 끼어들기도 합니다. "다들"이라고 부르면 모두 답합니다.
- 니케가 가끔 먼저 연락합니다. 하루 횟수와 시간대를 정할 수 있습니다.
- 대화가 길어지면 오래된 대화를 요약해서 기억합니다. 1:1에서 한 얘기를 단체방에서도 기억합니다.
- 읽음 "1", "입력 중…" 표시, 안 읽은 메시지 수가 나옵니다.

현재 들어 있는 니케: **스노우 화이트, 라푼젤, 홍련**, 단체방 **필그림**

> 비공식 팬 프로젝트입니다. 니케의 캐릭터와 이미지는 SHIFT UP의 저작물이므로, 게임 이미지는 저장소에 올리지 말고 내 PC에서만 사용하세요 (`public/images/nikke/` 는 git에서 제외되어 있습니다).

## AI

API 키 없이 **내 PC에 로그인된 CLI**를 사용합니다.

| provider | 필요한 것 | 특징 |
|---|---|---|
| `claude` | [Claude Code](https://claude.com/claude-code) 설치 후 로그인 | 캐릭터 연기 품질이 가장 좋음. Claude 구독 사용량을 씀 |
| `codex` | [Codex CLI](https://github.com/openai/codex) 설치 후 로그인 | ChatGPT 구독 사용량을 씀 |
| `ollama` | [Ollama](https://ollama.com) 설치 후 모델 받기 | 완전 무료. 품질은 모델과 그래픽카드 성능에 따라 다름 |

> CLI를 쓰는 방식은 **내 PC에서 나 혼자 쓰는 용도**로만 사용하세요. 이 앱에는 로그인 기능이 없어서, 인터넷에 공개하면 누구나 내 구독 사용량을 쓸 수 있습니다. 밖에서 폰으로 접속하고 싶다면 포트포워딩 대신 [Tailscale](https://tailscale.com) 같은 사설 VPN을 추천합니다.

## 실행 방법

```bash
cd nodejs
npm install
cp .env.example .env     # Windows: copy .env.example .env
# .env 에서 DB 주소와 LLM_PROVIDER 설정
npm run sync             # characters 폴더의 니케와 대화방을 DB에 반영
npm start
```

브라우저에서 `http://localhost:3000` 을 열면 됩니다.
같은 와이파이의 폰에서는 `http://<PC 내부 IP>:3000` 으로 접속합니다. Windows 방화벽에서 3000번 포트를 허용해야 할 수 있습니다.

### DB

MongoDB가 필요합니다. `.env` 의 `MONGODB_URI` 에 주소를 넣으세요.

- 기존 MongoDB Atlas 클러스터: 오래 안 쓰면 일시정지될 수 있습니다. Atlas 콘솔에서 다시 켜주세요.
- PC에 설치한 MongoDB: `MONGODB_URI=mongodb://127.0.0.1:27017/naru`

### 프로필 이미지

`nodejs/public/images/nikke/<characterID>.png` 에 넣으면 됩니다 (예: `snow_white.png`, `rapunzel.png`, `scarlet.png`, 단체방은 `pilgrim.png`).
이미지가 없으면 이름 첫 글자로 된 아바타가 나옵니다.

## 니케 추가·수정

니케 한 명은 `nodejs/characters/<characterID>.md` 파일 하나입니다.

| 파일 | 내용 |
|---|---|
| `_world.md` | 모든 니케가 공유하는 세계관 (방주, 랩쳐, 지휘관, 블라블라…) |
| `_rooms.json` | 단체방 목록과 멤버 |
| `_template.md` | 새 니케를 만들 때 복사할 양식 |
| `snow_white.md` 등 | 니케별 설정 |

1. `_template.md` 를 복사해서 `anis.md` 처럼 저장하고 채웁니다.
2. 단체방에 넣으려면 `_rooms.json` 에 추가합니다.
3. `npm run sync` 를 실행합니다.

설정 내용을 고치면 서버를 다시 켜지 않아도 다음 답변부터 반영됩니다. 이름, 이미지, 답장 속도, 단체방 구성을 바꿨을 때만 `npm run sync` 를 다시 실행하세요.

> 들어 있는 니케 설정은 나무위키·팬 위키 등의 공개 정보를 조사해서 쓴 것입니다(호칭: 스노우 화이트 "너", 라푼젤 "형제님", 홍련 "도령"). 게임 대사를 옮기지 않고 말투를 참고해 예시 대화를 새로 썼습니다. 게임과 다른 부분이 있으면 직접 고쳐 주세요.

### 캐릭터성을 살리는 팁

- **예시 대화가 가장 중요합니다.** 성격 설명을 길게 쓰는 것보다 실제로 보낼 법한 메시지 몇 줄이 말투를 훨씬 잘 잡아줍니다.
- 성격은 형용사("츤데레")보다 행동("걱정되면 오히려 퉁명스럽게 말함")으로 쓰세요.
- `## 말투` 섹션은 매 답변 직전에 한 번 더 상기시킵니다. 대화가 길어져도 말투가 흐려지지 않도록 짧고 구체적으로 쓰세요.
- 니케별로 다른 AI를 쓸 수 있습니다. 파일 맨 위의 `provider:` / `model:` 에 적으면 됩니다.

## 기억

- **대화방 기억**: 요약되지 않은 메시지가 `MEMORY_COMPACT_THRESHOLD`(기본 40개)를 넘으면, 최근 `MEMORY_KEEP_RECENT`(기본 20개)만 원문으로 남기고 나머지를 요약합니다.
- **니케 개인 기억**: 요약할 때 참여한 니케 각자의 기억도 갱신합니다. 어느 방에서든 그 니케는 지휘관과의 지난 일을 기억합니다.
- **다른 방의 최근 대화**: 최근 48시간 동안 같은 니케가 참여한 다른 방의 대화도 참고합니다.
- 요약은 답장 후 백그라운드에서 진행됩니다. 구독 사용량을 아끼려면 `SUMMARY_PROVIDER=ollama` 로 요약만 로컬 모델에 맡길 수 있습니다.

## 먼저 연락하기

20분마다 각 대화방을 확인해서, 조건이 맞으면 니케가 먼저 메시지를 보냅니다.

- 마지막 대화 후 `PROACTIVE_MIN_GAP_HOURS`(기본 3시간)가 지났을 것
- 니케의 `active_hours` 시간대일 것
- 그 니케가 오늘 `PROACTIVE_MAX_PER_DAY`(기본 2회)만큼 연락하지 않았을 것
- 이전에 먼저 보낸 메시지에 지휘관이 답했을 것 (답이 없으면 연달아 보내지 않음)

끄려면 `.env` 에서 `PROACTIVE_ENABLED=false`, 특정 니케만 끄려면 설정 파일에 `proactive: false`.

## 참고

- 캐릭터 연기는 `CLAUDE_MODEL=sonnet` 이상을 추천합니다. haiku는 말투가 밋밋해지고 기억을 자주 헷갈립니다. sonnet 기준 답장 생성에 5~10초 정도 걸립니다.
- 단체방에서 여러 명이 답하면 앞사람 말을 보고 답하도록 한 명씩 차례로 답합니다.
- Claude는 모든 도구(파일 읽기, 명령 실행 등)를 끈 상태로, Codex는 읽기 전용 샌드박스로 빈 임시 폴더에서 실행합니다.
