# 실제 대사 샘플 폴더

게임에서 모은 캐릭터의 실제 대사를 `<characterID>.md` 로 넣어 두면
(예: `snow_white.md`, `rapunzel.md`, `scarlet.md`) 답장할 때 말투 참고 자료로 쓰입니다.

- 형식은 자유입니다. 대화 그대로 옮겨도 되고, 대사만 한 줄씩 적어도 됩니다.
- 블라블라 대화, 로비 대사, 호감도 스토리 대사 등 무엇이든 좋습니다.
- 너무 길면 프롬프트가 무거워지니 캐릭터당 30~60줄 정도를 추천합니다.
- 이 폴더의 파일은 게임 저작물이므로 git에 올라가지 않습니다 (이 README만 올라감).
